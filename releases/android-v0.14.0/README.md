# Android V14 — arena's en ultimate power

[Download de aparte V14-preview-APK](https://github.com/Icyman86/InfernoDuel/raw/refs/tags/v0.14.0-android-preview/releases/android-v0.14.0/InfernoDuel-Android-v0.14.0-preview.apk).

Installeert als **Inferno Duel V14 Preview**, naast de bestaande app. Dit is geen
update die V11 overschrijft. Gebruik op beide apparaten deze preview voor LAN-play.

Gekozen maps: **Nachtelvenbos — Hart van het Bos (A3)** en **Spinegrins
ruimteschip — Levende Brug (B1)**. Na character select: map kiezen of RANDOM.
In een sessie kiest de host en laden beide apparaten dezelfde arena.

Ultimate: grote melding, aura/ACTIVE-knop van drie seconden en +20% schade op
vervolgaanvallen; geen stapeling met bestaande empowerment.
