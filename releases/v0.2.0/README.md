# Inferno Duel: Legends — visual update v0.2.0

[Download Linux v0.2](https://github.com/Icyman86/InfernoDuel/raw/refs/tags/v0.2.0/releases/v0.2.0/InfernoDuel-Linux-v0.2.tar.xz)

[Watch the animation preview](https://github.com/Icyman86/InfernoDuel/raw/refs/tags/v0.2.0/releases/v0.2.0/InfernoDuel-AnimationPreview-v0.2.mp4)

Pak het `.tar.xz`-archief uit en start `PLAY.sh` in `InfernoDuel-Linux`.
Vereist Linux x86_64 met OpenGL 3.3; Godot is in het pakket opgenomen.

Nieuw ten opzichte van v0.1:

- Geïllustreerde sprites en animatiestaten voor SharkByte en Bullet, gebaseerd
  op de aangeleverde characterbladen. Bullet volgt nu het menselijke ontwerp.
- Avatars voor alle tien fighters, geanimeerde previews voor de twee speelbare
  fighters, portretten in HUD/arena/gallery en een winnaarfiguur in de uitslag.
- Nieuwe Infernal Citadel-art, hero-menu, selectielayout, impacteffecten en trails.
- 70 gevechts-/flowchecks, 103 spritechecks en negen grafische checks geslaagd.

De preview is een gescripte animatiereview vanuit Godot, geen opgenomen wedstrijd.
De spriteframes zijn nieuwe referentiegestuurde gegenereerde afgeleiden. De acht
originele character-/movesheets zijn byte voor byte behouden. Acht roster-fighters
hebben een avatar maar zijn nog niet volledig speelbaar. Extra tussenframes en een
handmatige art-/balansreview blijven vervolgstappen.

P1: A/D, W, S, F/G/H/J. P2: pijltjes, I/O/P/L. Esc pauzeert.
Controleer de bestanden met `sha256sum -c SHA256SUMS`.
