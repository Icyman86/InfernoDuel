# Inferno Duel Linux V12 — 0.12.0 preview

Speelbaar 3D-techniekprototype met controllers, directionele commando's,
grabs/throws, break-free en aangekondigde klemvallen. De echte volumemodellen
zijn eenvoudig en procedureel; dit is nog geen voltooide moderne 3D-fighter.
Zie [bediening, spelregels en beperkingen](../../docs/V12_LINUX.md).

Download `InfernoDuel-Linux-v0.12.0-preview.tar.xz`, pak uit en start
`InfernoDuel-Linux/PLAY.sh`. Linux x86_64/OpenGL 3.3, engine inbegrepen.
Geen nieuwe Android/iOS-build. Eerdere publicaties blijven behouden.
