Inferno Duel 0.9 iPhone sideload preview.

Download `InfernoDuel-iPhone-v0.9.0-unsigned.ipa`, then install and sign it using
AltStore Classic + AltServer on Windows or Mac and your own Apple Account.
The attached Dutch IPHONE_INSTALLATIE.md explains installation, Developer Mode
and seven-day renewal with a free account. Opening the IPA in Safari does not
install it. No Apple credentials, production signing keys or profiles are included.

iOS 15+, ARM64 device build, landscape/native resolution, touch controls,
ten fighters, all 69 moves, V9 continuous attack animation, 200 HP and golden
ultimate-ready HUD. Same-Wi-Fi session codes use bounded private-/24 unicast
lookup on iPhone. Use Android as host when pairing with the retained Android V9
APK; physical cross-device discovery remains unverified. No Internet relay.

This release is published only after macOS/Xcode builds the real device app and
the IPA passes executable/platform/version, plist, ZIP CRC and every game-pack
file hash check. A real iPhone installation, Apple-account re-signing, Metal
rendering, audio, safe-area/rotation, Wi-Fi and frame pacing still need acceptance.
